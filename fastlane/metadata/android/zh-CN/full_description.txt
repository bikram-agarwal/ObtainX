ObtainX 是 Obtainium 的现代化强化分支。采用全新的 Material 3 Expressive 界面，并内置多项进阶工具，让管理应用变得轻松自如。直接从原始来源获取更新：GitHub、GitLab、F-Droid、IzzyOnDroid、APKMirror、APKPure 等。无中心仓库，无账号，无追踪。🚀

<b>━━ ✨ 独有功能（Obtainium 没有）━━</b>

• <b>构建验证</b> —— 通过加密校验（F-Droid/Izzy 的可复现构建与 GitHub Release Attestations）在安装前标记被篡改的安装包。ObtainX 自身的更新同样附带 GitHub 证明。
• <b>第三方安装器支持</b> —— 将更新交给 InstallerX 或 App Manager 等安装器，查看系统安装器隐藏的 APK 元数据。在“高级保护”下尤为必要。
• <b>从设备批量导入</b> —— 选择手机上已有的应用，ObtainX 会自动查找其来源，无需自行搜寻 URL。
• <b>动态文件夹</b> —— 命名文件夹，可手动或按规则（名称、作者、包 ID、类别或来源）归类；每个文件夹保留自己的布局。
• <b>按需更新模式</b> —— 将很少更新的应用从主列表隐藏，并在全局扫描中跳过；只在需要时检查。
• <b>可配置滑动手势</b> —— 每一行左右两侧各自独立：更新、安装、置顶、编辑、删除等。
• <b>自定义应用图标</b> —— 从相册或网络为任意应用设置图标。
• <b>删除后可撤销</b> —— 滑动删除和批量删除都会显示 5 秒撤销提示条。
• <b>已验证的“也可在此获取”链接</b> —— 每个应用会显示已确认上架的其他商店。
• <b>正则助手</b> —— 内置向导带你构建版本与 APK 筛选规则，无需懂正则。
• <b>提前查看更新大小</b> —— 更新前即可看到确切的下载大小。
• <b>跳过版本</b> —— 跳过某个发布，而不把应用标记为“已更新”。
• <b>停止下载</b> —— 可在应用内、通知或队列中取消正在进行的下载。
• <b>保存安装包</b> —— 更新过程中可将下载的 APK 保存到你指定的文件夹。

<b>━━ 🔧 增强功能 ━━</b>

• <b>APKMirror 更新</b> —— 已启用（上游默认关闭），并会直接打开对应的发布页面。
• <b>更智能的版本状态</b> —— 用六种状态取代“有更新/已是最新”的二元判断。
• <b>添加应用的三种方式，一屏完成</b> —— URL、搜索与从设备三个入口集中在分段控件中，结果就地展示。
• <b>可编辑包 ID</b>（用于仅追踪来源）—— 恢复正确的安装检测与更新。
• <b>生效中的筛选标签</b> —— 每个生效的筛选对应一个可移除标签，点按即可清除。
• <b>类别自定义</b> —— 任意颜色、重命名与批量分配。

<b>━━ 🎨 界面与交互 ━━</b>

• <b>适配平板、折叠屏与横屏布局</b> —— 大屏下由侧边导航栏取代底部栏，应用列表与详情页并排显示，应用就地打开。添加与批量导入同样采用双栏布局，并在横屏下自适应 —— 大屏手机与折叠屏也能受益，而不只是平板。
• <b>全界面 Material 3 Expressive</b> —— 卡片、流畅动画、表现力控件。
• <b>完整的主题引擎</b> —— 跟随系统/浅色/深色/AMOLED 主题，Material You 或任意十六进制颜色，9 种调色算法，阴影、渐变、渐进模糊、圆角与界面缩放。
• <b>按应用配色</b> —— 从每个应用自身的图标提取主题色。
• <b>可自定义应用行</b> —— 一眼可见应用类型、来源与类别，可选文字标签或极简色条。
• Hero 图标转场、就地展开搜索、详情页就地编辑、来源图标角标，以及自动隐藏的操作栏。

<b>━━ 🔄 从 Obtainium 迁移数据 ━━</b>
在 Obtainium 中把应用列表导出为 .json 文件（导入/导出 → 导出）。在 ObtainX 中打开备份标签页并导入，追踪的应用会立刻出现。
